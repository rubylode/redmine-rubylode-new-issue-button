# Roadmap

## Built

- The New issue button on every page, decided by the server: the project's form inside a project, the global form
  elsewhere, only for a signed-in user who may add issues.
- A plain stylesheet a theme can override, and a hidden button on the phone layout.
- Version 2.0.0 follows the Rubylode plugin standard. The plugin has no settings.

## Open

- Whether to hide the button on the phone layout or offer a compact one.
- Translations of the fallback label (the label itself comes from Redmine's own locale files).
